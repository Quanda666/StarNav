# 邮箱通知配置指南

星漫旅站支持把站点事件推送到邮箱，路径：**后台 → 邮箱通知**。

---

## 一、会发哪些邮件

| 事件 | 收件人 | 触发时机 |
|---|---|---|
| 新书签提交提醒 | 管理员（配置的收件人） | 访客在前台提交书签后立即发送 |
| 审核通过通知 | 提交者（若填写了邮箱），否则管理员 | 后台点「批准」后 |
| 审核未通过通知 | 提交者（若填写了邮箱），否则管理员 | 后台点「拒绝」后（含拒绝理由） |
| 链接异常告警 | 管理员 | 定时任务健康检查发现不可用书签时汇总发送 |
| 站点摘要 | 管理员 | 每天到达配置的北京时间整点且当天未发过（需开启） |
| 测试邮件 | 管理员 | 后台点「发送测试邮件」 |

前台提交表单新增了**可选**的「邮箱」字段，仅用于接收审核结果，不会公开展示。

> 通知都是异步发送（`ctx.waitUntil`），失败只写日志，**绝不影响**提交、审核、健康检查等主流程。

---

## 二、选择发送方式

### 方式 1：Resend（推荐，最省事）

1. 注册 [resend.com](https://resend.com)，创建 API Key（`re_` 开头）；
2. 在 Resend 里验证一个发件域名（或先用官方测试域名）；
3. 后台「邮箱通知」：发送方式选 **Resend**，填发件人邮箱、收件人、API Key；
4. 保存后点「发送测试邮件」。

限制：免费额度为每天 100 封 / 每月 3000 封，个人站点足够。

### 方式 2：SMTP 直连（用你自己的邮箱发）

Workers 通过 `cloudflare:sockets` 直连 SMTP，支持 TLS / STARTTLS。

| 邮箱 | 服务器 | 端口 | 加密 | 用户名 | 密码 |
|---|---|---|---|---|---|
| QQ 邮箱 | smtp.qq.com | 465 | TLS | 完整邮箱地址 | **授权码**（非登录密码） |
| 163 邮箱 | smtp.163.com | 465 | TLS | 完整邮箱地址 | 授权码 |
| Gmail | smtp.gmail.com | 465 | TLS | 完整邮箱地址 | **应用专用密码** |
| Outlook | smtp.office365.com | 587 | STARTTLS | 完整邮箱地址 | 账号密码 / 应用密码 |
| 自建 Postfix | 你的域名 | 465 / 587 | TLS / STARTTLS | 按服务器配置 | 按服务器配置 |

要点：

- QQ / 163 / Gmail 都必须用**授权码或应用专用密码**，不是账号登录密码；
- 587 端口请把加密方式切到 **STARTTLS**；465 用 **TLS**；内网明文中继选 **none**；
- 发件人地址建议与 SMTP 用户名一致，否则容易被判为伪造发信人（SPF 校验失败）；
- 部分服务商对「发件人 ≠ 用户名」会直接拒收（错误码 553 / 550）。

### 方式 3：HTTP 中继

适合自建 Serverless 函数或企业网关。后台填中继地址与 Token，系统会发送：

```http
POST <你的中继地址>
Authorization: Bearer <配置的 Token>
Content-Type: application/json
X-StarNav-Event: submission

{
  "from": "星漫旅站 <noreply@your-domain.com>",
  "to": ["admin@your-domain.com"],
  "subject": "【新书签提交】…",
  "html": "<!DOCTYPE html>…",
  "text": "…"
}
```

中继只需返回 2xx 即视为成功。

## 三、事件开关

在配置页可分别开关：新提交提醒、审核结果通知、链接异常告警、定期摘要，并可设置摘要的**发送整点**（北京时间 0–23）与周期（周 / 月）。

定时任务（Cron）默认随健康检查与备份一起跑；摘要只会在「当前北京时间小时 == 配置小时」且当天未发送时发出，不会重复轰炸。

---

## 四、邮件长什么样

模板为内联样式 + 表格布局，兼容 Gmail / Outlook / QQ 邮箱与移动端，并带深色模式适配：

- 顶部品牌渐变头图（不依赖外部图片，避免被图片代理拦截）；
- 事件卡片：站点信息行 + 标签药丸 + 推荐理由引用块；
- 圆形渐变按钮（仅当配置了可通过邮件访问的站点地址时才显示，避免出现无效链接）；
- 摘要使用四宫格数据卡 + 最近收录列表。

后台「邮箱通知」页可以**预览全部 6 种模板**（下拉选择 → 预览模板），所见即所得。

> 想让邮件里的按钮生效，需要在 Worker 配置环境变量 `SITE_URL`（例如 `https://nav.example.com`），否则按钮会被省略。

## 五、排错

1. **先看「最近发送记录」**：每条都记录了时间、收件人、方式、成功/失败与错误摘要。
2. 常见错误：
   - `Resend 返回 401/403`：API Key 无效或域名未验证；
   - `SMTP greeting 超时`：服务器地址或端口填错，或被云厂商限制出站 25 端口（改用 465/587）；
   - `SMTP auth 失败`：用了登录密码而非授权码；
   - `SMTP rcpt-to 失败 550`：收件人被服务器拒收；
   - `没有有效收件人`：收件人格式不合法（会被自动过滤）。
3. **「发送测试邮件」用的是当前表单值**，因此可以先不保存、直接试通再保存。
4. 端口连通性由 Workers 出口决定：Cloudflare 不允许直连 25 端口，请使用 465 / 587。

---

## 六、安全说明

- API Key / SMTP 密码使用 AES-GCM 加密后存 D1（主密钥来自 `env.SECRET_KEY`）；
- 配置接口只允许管理员会话访问（不接受 API Token）；
- 邮件模板对所有用户输入做 HTML 转义，且只允许 `http(s)` 链接进入 `href`；
- ⚠️ 更换 `SECRET_KEY` 会导致已保存的密钥无法解密，需要重新填写。
